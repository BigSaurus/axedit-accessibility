Axe-Edit III Accessibility

An NVDA add-on that makes Axe-Edit III (Fractal Audio's editor for the Axe-Fx III) usable with a screen reader. Axe-Edit is a native JUCE application whose controls often hide their value in the control name, fire no change events, or report contradictory state. This add-on fixes those so you can hear what you are doing and move around the grid by keyboard.

Author: Big Saurus. License: GNU GPL v2. Project home & updates. This is an early release — more features and regular updates are on the way.

Which editors are supported

Axe-Edit III is the one that has been tested against real hardware.

Experimental, untested support is also included for FM9-Edit and FM3-Edit. Fractal's editors are built from a shared codebase and this add-on relies on the control naming that codebase produces, so the fixes are expected to apply — but nobody has confirmed it yet. If you own an FM9 or FM3 and try it, please get in touch: open the editor, press NVDA+Shift+D, and send the file that appears on your Desktop along with a note about what did and didn't work. That is enough to fix whatever is off.

What it does

  • Speaks values as you change them. Slider/knob and combo-box values (which live in the control name and fire no event) are re-read after each arrow key, so you hear "Gain: 3.40" as you turn it — without the repetitive "Modifier Disabled".
  • Clean grid-cell state. Each grid cell says its block and bypass state ("Amp 1A, Active" / "Delay 1A, Bypassed") instead of the default contradictory "Active … not checked".
  • No routing-graphic spam. The 169 unlabelled jack/cable graphics are suppressed from focus and object navigation.
  • Fast 2D grid navigation by keyboard (see below).

Keyboard commands

These apply while Axe-Edit III is focused.

On a grid cell

KeyAction
Arrow keysMove between grid cells (2D). Announces "Grid row R column C: block, state".
Home / EndJump to the first / last column of the current row.
EnterSelect the block under focus so its parameters load in the parameters panel.
SpaceBypass or re-enable the block, then speak its new state. Focus stays on the cell — Axe-Edit normally drops focus entirely when a block is toggled.

On an on/off button

Buttons such as Bypass, Scene Ignore, Channel A–D and the scene buttons are mouse-only in Axe-Edit — pressing them normally drops keyboard focus. Their built-in labels are unreliable, so the add-on relabels them to their true state, e.g. "Channel C off" / "Channel C on".

KeyAction
EnterToggle the button. For a channel button, focus then lands on the combo box just below the channels (the channel buttons themselves cannot hold keyboard focus), so Tab and Shift+Tab keep working. Space is left for bypassing blocks on the grid.

Anywhere in Axe-Edit

KeyAction
NVDA+Ctrl+0 … 9Jump straight to the main signal row (row 2), that column. For example NVDA+Ctrl+5 is the amp. Columns 10–13 are reached with the arrows or End.
NVDA+Shift+AJump to the Amp block.
NVDA+Shift+EJump to the Effects grid (row 0, column 0).
NVDA+Shift+FJump to the first parameter of the current block.
NVDA+Shift+PJump to the Preset selector.
NVDA+Shift+SJump to the Scene selector.
Alt+P / Alt+B / Alt+T / Alt+S / Alt+HOpen the Preset, Block, Tools, Settings or Help menu (these are mouse-only in Axe-Edit).
NVDA+Shift+IAnnounce full info about the focused control.
NVDA+Shift+GToggle 2D arrow-key grid navigation (default on).
NVDA+Shift+JToggle jack/cable noise suppression (default on).
NVDA+Shift+DSave a diagnostic dump of the current editor window to your Desktop (used to add support for other Fractal editors).
NVDA+Shift+SpaceActivate the focused control (for items that only respond to a mouse click).

Notes

  • If a preset places its chain on a row other than row 2, the number-key jumps still target row 2; use the arrows to reach other rows. A future update may make this follow your last position.
  • The right-click "add block" menu is not yet accessible (Axe-Edit exposes it only through IAccessible2); that is planned as a separate piece of work.
  • Pressing Enter on a model selector opens Axe-Edit's full-window model picker, whose entries are drawn graphics with no accessible identity, so a screen reader cannot read them. NVDA will tell you the list is open but inaccessible — press Escape to close it and change the model with the arrow keys instead (which are spoken as you go).
  • Found a rough edge? Reports are welcome at the project home linked above.
